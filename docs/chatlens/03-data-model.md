# Data model and metrics

Message: source/account scope, group_id, stable message_id, sender pseudonym, sent_at (timezone-aware), kind, text, media_refs, link metadata, forward children, reply_to, local evidence locator. MediaRef: local relative path, mime, content hash, dimensions/frame count when available, status and reason. Keep original local records immutable. Stable ID collision handling and import idempotence required.

AnalysisRun: snapshot_id, selected date/group, analyzer/config versions, model IDs, prompt hashes, stages, coverage, started/finished, errors, artifact paths. Relation: ordered message IDs, relation type, detector/model version, scores (uncalibrated unless evaluated), evidence, review status. Cluster: representative, member IDs, first/last seen in selected range, occurrence counts, unique sender count, relation basis. Report section: data provenance, metric definitions, evidence IDs and limitations.

Metrics: total top-level messages; eligible by type; analyzed by type; missing/unresolved by type; confirmed duplicate occurrences = sum(cluster size - 1) for disjoint duplicate clusters; denominator = eligible successfully analyzed top-level messages of applicable type. Report coverage = analyzed/eligible separately. Do not double count image/link/text flags on one message. Overall rate only across clearly defined eligible union; unresolved counts and uncertain pairs separate. Reuse frequency = all occurrences including representative. Same-event-with-update and same-template relations are not duplicates. Zero denominator = N/A. Timezone shown; first appearance only within available snapshot. Raw IDs never in shared report by default.
