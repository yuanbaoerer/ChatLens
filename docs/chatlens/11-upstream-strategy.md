# Upstream and distribution

Upstream: https://github.com/mofan6/Moect ; fork: https://github.com/yuanbaoerer/ChetLens . Preserve upstream Git history, GPL-3.0 LICENSE, attributions and copyright notices. Personal private changes and distribution obligations differ; when distributing modified covered software provide corresponding source and required notices under GPL-3.0, review dependency licenses. No claim of official affiliation. Upstream README announces potential compatibility/DMCA risk and a maintenance pause; avoid embedding new credential extraction or access bypass. Maintain independent authorized export fallback.

Use main for reviewed fork changes, feature branches for tasks, PRs targeting fork main. Record upstream baseline commit, periodically merge reviewed upstream changes on dedicated sync branch; run existing build and regression checks plus analytics tests. Keep analytics independent and UI/service diff small. Do not overwrite upstream README or license at planning stage. When packaging, fork release metadata, updater behavior and storage namespace must be audited to prevent upstream replacement or destructive collisions. Windows-first; no promise of macOS support. If upstream unavailable, analysis of existing authorized exports remains usable. No auto-merge.
