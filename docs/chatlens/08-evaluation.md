# Evaluation and release gates

Synthetic fixtures plus authorized local labeled Chinese examples (target >=300 pairs, split by event/template into calibration and holdout; no real samples in Git). Include exact repeats, compressed/cropped image, GIF variants, changed captions, short banter, paraphrases, forwarded articles, event updates, negations, conflicting numbers, irrelevant near-topic and uncertain examples. Track candidate recall separately from judge quality and end-to-end cluster quality.

Compare A deterministic baseline; B embedding only; C embedding+Jev; D embedding+LLM judge on same frozen candidate pairs and holdout; also full pipeline retrieval. Report precision/recall/F1, confusion matrix, Recall@K, false merge rate for updates/contradictions, cluster purity, cost per 1k messages, call count, P50/P95 latency and repeated-run consistency. Suggested targets (not verified): exact fixtures 100%; semantic precision >=95%, recall >=85%, update false merge <=5%, Recall@K >=95%. Report denominators, confidence/limitations and sample size; missed targets block automated confident merge or require explicit review, not fake success.

LLM: evidence IDs valid, quotes exact, stats match computed data, topic coverage against human annotations, injection/adversarial inputs, humor grounded and non-abusive. Automated schema and citation checks + manual sample review. Regression: existing Moect build/export/demo, analytics unit/integration and synthetic desktop workflow; actual Windows run required for release, disclose skipped tests. Release acceptance includes no sensitive files/logging, provider opt-in, cancellation/partial report, and GPL compliance.
